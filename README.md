# Shopping System — Java OOP

A pair academic project combining requirements and UML design with a Java console implementation for customers, inventory, carts, discounts, simulated payments and receipts.

## Technologies and skills

Java, inheritance, abstract classes, interfaces, polymorphism, custom exceptions, file output.

## Authorship and scope

My documented contribution covers discount policies, payment classes, receipts, checkout calculations and the console interface. Hussein Musab Abdi contributed the customer, inventory, cart and exception components. Integration and review were shared.

## Run locally

Requires a Java JDK. From the repository folder:

```sh
javac -d out src/shoppingsystem/*.java
java -cp out shoppingsystem.ShoppingSystemApp
```

Payments are simulated. Sample customer and product records are educational fixtures.
